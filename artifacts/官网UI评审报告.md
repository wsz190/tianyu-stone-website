## 二、专家评审意见

### 2.1 UI/UX 交互专家

**P1-1 表单输入字号 15px < 16px（移动端）**
iOS Safari 对 <16px 的输入框聚焦时会自动放大页面，用户填写"手机号/留言"时页面突然缩放，体验割裂。这是移动端表单的真实痛点。
→ 建议：input/textarea font-size 提升至 16px（同时提升可读性）。

**P1-2 公告正文 13px + 桌面行宽过长**
公告正文 13px 偏小（正文推荐 ≥15–16px）；桌面一行实测 1166px，约 90 字符/行，超过 75 字符可读上限，长行阅读费眼。
→ 建议：正文 15px；公告列表容器限制 `max-width: 72ch`。

**P2-1 触控目标偏小**："发送"42px、"往下看"33px、Menu 43×31 均 <44px，误触率上升。
→ 建议：`min-height:44px` + 扩大 padding/hit 区域。

**P2-2 移动端水平留白 20px 偏紧**，建议 24px，与大厂移动端习惯一致。

**P2-3 表单缺少输入中错误态**：当前仅手机号格式校验有提示；建议保留字段级错误文案（评分：次要，MVP 可后置）。

### 2.2 视觉与品牌设计专家

**达成度评价（高）**：
- 深色石材（#15130f/#0c0b09）+ 暖象牙（#ebe5d8）+ 青铜金（#a88a5e/#c7aa7c）token 体系全局统一，无散落色值；
- 宋体（Songti SC / Noto Serif SC）大标题 + 主标语三行排布，气质高级、克制；
- 直角按钮、大留白、统计数字 202px 的版面冲击力，符合"高端简洁大气"诉求。

**优化建议**：
- **P2-4 按钮文字 11px 相对 52px 按钮视觉失衡**：11px 偏"微型"，与按钮体量不匹配，建议 13–14px + 字距微调。
- **P2-5 首屏标签 11px 可提升至 12–13px**，同时保留 3.3px 字距，进一步强化"石材质感标签"的精致度。
- 小建议（可选）：案例区"年份 2026"为占位，上线前替换真实年份或删除该字段，避免被访客理解为固定宣传口径。

### 2.3 前端工程与可访问性专家

- **对比度全面达标（≥8.37:1）**，深色主题无可读性风险，无需调整配色；
- 响应式缩放（标题 115→84→44、留白 clamp）实现干净，无横向滚动；
- **P2-6 补 3 张图片 alt**（process-waterjet / case-bathroom / experience 背景板），利于 SEO 与读屏；
- **P2-7 焦点可见性**：outline 1px 偏细，建议 2px + 对比色（金色 #c7aa7c）；
- 已确认具备：prefers-reduced-motion 降级、字体随系统、懒加载图片（8/8 实测加载成功）；
- 待上线补充：favicon 已补（本轮已修复）；页面加载首屏 3D 在低端机自动降级 CSS 背景图 ✓。

## 四、评审结论

1. **视觉与品牌层面**：高端简洁大气目标达成，无需推翻重做；
2. **可读性层面**：对比度极佳，主要风险在"字号偏小 + 行宽过长"两处 P1；
3. **移动端体验**：触控与 iOS 输入缩放两处需优先处理；
4. **建议**：上线前处理 2 项 P1；P2 项按排期消化（推荐全量处理，成本低）。
